# DevProtector

Native Tauri 2 + Rust app that watches your dev folders in real time and blocks supply-chain attacks (the "fake interview task" npm malware, malicious postinstall scripts, obfuscated loaders, keychain/SSH exfil, etc).

## What it does

- **Real-time file watcher** (via `notify`/FSEvents) on folders you choose (e.g. `~/code`, `~/projects`).
- **Rule engine** scans each new/modified file against 20+ patterns: `eval(Buffer.from(…base64…))`, `curl | bash`, `~/.ssh/id_rsa` reads, keychain/Chrome Login Data access, MetaMask/Phantom/Exodus wallet scans, reverse-shell strings, AppleScript phish dialogs, package.json pre/postinstall, known-bad dependency names.
- **Auto-response**: detected file is moved to `~/.devprotector/quarantine/` (permissions stripped) and any process executing it is SIGKILL'd.
- **Process scan**: enumerates `npm`/`pnpm`/`yarn`/`node`/`python`/`bash` running inside monitored folders.
- **Network scan**: `lsof`-based outbound TCP enumeration, flags known exfil hosts (transfer.sh, requestbin, ngrok, duckdns, …).
- **Dashboard UI**: monitored folders, live detections feed, quarantine (restore/delete), settings toggles, process + network scans.

## Run

```bash
# deps: Rust, Node 20+, Xcode CLT on macOS
cd src-tauri && cargo tauri dev      # live-reload dev
cd src-tauri && cargo tauri build    # production bundle
```

## Tests

Fully automatable. Two layers:

### 1. Rust integration (`src-tauri/tests/detection.rs`)
Verifies the scanner against the `~/code/bad` fixture and clean-file negatives.
```bash
cd src-tauri && cargo test --test detection
```

### 2. WebDriver end-to-end (`tests/e2e.mjs`)
Launches the real Tauri binary through `tauri-wd` (W3C WebDriver for WKWebView on macOS) and drives it with `selenium-webdriver`. Covers: add folder, `force_check`, quarantine, live watcher detection of a newly-written bad file, UI DOM rows, restore flow.
```bash
bash scripts/run-all-tests.sh
```

The runner boots `tauri-wd --port 4455`, spawns the debug build, calls each Tauri command via `executeAsyncScript`, and asserts. Run in CI on macOS with no manual steps.

## Fixture

`~/code/bad/` is an inert positive-match fixture (no live exploit). Regenerated by the test runner before each e2e run.

## Threat model covered

- Malicious `preinstall`/`postinstall`/`install` scripts
- `curl … | bash` / `wget … | sh` installers
- Obfuscated loaders: `eval(Buffer.from(…,'base64'))`, `new Function(atob(…))`, long hex/unicode blobs
- Credential theft reads: `~/.ssh/id_*`, `~/.aws/credentials`, `Library/Keychains/login.keychain-db`, Chrome/Brave/Edge/Firefox login data, MetaMask/Phantom/Exodus/Atomic/Electrum wallet dirs
- Reverse shells (`bash -i >& /dev/tcp/...`, `nc -e`, `python -c "import socket"`)
- AppleScript password phish (`osascript -e 'display dialog …'`)
- Exfil to hostile hosts (transfer.sh, webhook.site, requestbin, glitch.me, ngrok, duckdns, raw IPs)
- Known-bad package typosquats (flatmap-stream, event-stream-bad, etc.)

## Config

`~/.devprotector/config.json` persists monitored folders and protection toggles. `~/.devprotector/quarantine/index.json` tracks quarantined items.
